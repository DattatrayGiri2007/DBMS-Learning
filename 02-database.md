# 02 — Database

## What is a Database?

A **database** is a collection of related data stored in an organized way.

### Example

A college database can store:

- Student name
- Roll number
- Course
- Marks
- Attendance

### Example Table

| Roll No. | Name | Course | Marks |
|---:|---|---|---:|
| 1 | Rahul | BCA | 75 |
| 2 | Amit | BCA | 80 |
| 3 | Datta | BCA | 85 |

All this student data stored together in an organized way is called a **database**.

### Easy way to remember

> **Data = Individual / raw facts**  
> **Database = Organized collection of data**

### Definition

> A database is an organized collection of related data that can be easily accessed and managed.
