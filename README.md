My Database Management System (DBMS) learning repository as a FY BCA student.

This repository contains my **classroom notes, simplified explanations, examples, and SQL practice** while learning DBMS.

## 🧠 Learning Approach

```text
Learn → Understand → Practice → Document → Revise
```

My handwritten classroom notes are the starting point. I use digital notes to organize the concepts and make them easier to revise.
