# 04 — RDBMS

## What is RDBMS?

**RDBMS** stands for **Relational Database Management System**.

It is a type of DBMS that stores data in the form of **tables**.

A table consists of:

- Rows
- Columns

### Example

| ID | Name | Course | Marks |
|---:|---|---|---:|
| 1 | Rahul | BCA | 75 |
| 2 | Amit | BCA | 80 |
| 3 | Datta | BCA | 85 |

Here, data is stored in rows and columns, which form a table.

### Why is it called Relational?

Tables can be related to each other.

> **RDBMS → DBMS that stores data mainly in related tables.**

### Examples

- PostgreSQL
- MySQL
- Oracle
- Microsoft SQL Server
