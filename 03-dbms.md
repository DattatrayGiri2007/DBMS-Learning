# 03 — DBMS

## What is DBMS?

**DBMS** stands for **Database Management System**.

A DBMS is software that helps us to create, store, manage, update, and access data in a database.

### Example

Suppose a college has:

| Roll No. | Name | Marks |
|---:|---|---:|
| 1 | Rahul | 75 |
| 2 | Amit | 80 |
| 3 | Datta | 85 |

The DBMS helps us to:

- Add a new student
- Change a student's marks
- Find a student's details
- Delete a student's record

### Examples of DBMS

- MySQL
- Oracle
- Microsoft SQL Server
- PostgreSQL

### Simple Definition

> A **Database Management System (DBMS)** is software used to create, store, manage, and access data from a database.
