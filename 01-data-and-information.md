# 01 — Data and Information

## What is Data?

**Data is raw information.**

Data is a collection of raw facts and figures that can be processed to obtain meaningful information.

### Example

```text
Datta, 19, BCA, 16, Pune
```

| Data | Represents |
|---|---|
| Datta | Name |
| 19 | Age |
| BCA | Course |
| 16 | Roll No. |
| Pune | City |

At this stage, they are just **raw facts**.

## Data vs Information

```text
Data → Processing → Information
```

### Example

**Data:**

```text
70, 80, 90
```

After processing:

```text
Information: Average marks = 80
```

### Easy way to remember

> **Data = Raw material**  
> **Information = Useful result obtained after processing the raw data**

## Types of Data

| Type | Example |
|---|---|
| Text | Datta, BCA |
| Number | 19, 85, 5000 |
| Image | Student photo |
| Audio | Voice recording |
| Video | Lecture video |
| Date/Time | 29/09/2026, 10:30 AM |
